# Transit Construction | North America + Europe

An editorial-style interactive map tracking major transit construction projects across North America and Europe.

The `expansion/europe` branch is the first Europe coverage pass. It adds a small, source-backed set of projects while the main branch remains the North America release.

It combines real project data, corridor geometries, and point markers into a magazine-like layout for browsing active rail, LRT, and BRT builds.

Built for GitHub Pages deployment.
